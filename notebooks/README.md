# Notebooks — SupplySight AI

## Purpose

Jupyter notebooks for data understanding, cleaning, EDA, feature engineering, model training, and evaluation. Notebooks are for exploration; production training should migrate into `ml/training/`.

## Contents

| Notebook | Focus |
|----------|--------|
| `01_data_understanding.ipynb` | Source inventory and schema profiling |
| `02_data_cleaning.ipynb` | Quality rules and cleaning steps |
| `03_exploratory_data_analysis.ipynb` | EDA and visualizations |
| `04_feature_engineering.ipynb` | Feature design experiments |
| `05_model_training.ipynb` | Baseline model experiments |
| `06_model_evaluation.ipynb` | Metrics, SHAP, error analysis |
